# Криптопрогнозирование

Ориентир цены криптовалюты на 24 и 48 часов и калиброванный коридор вокруг него. Не торговый совет и не обещание точной цены.

Сайт считает:

1. **Сейчас** — живая цена с Binance.
2. **Ориентир** — куда модель клонит цену за сутки и двое (техника, волатильность, новости, страх/жадность).
3. **Коридор** — зона, внутри которой цена скорее всего проживёт это время (цель покрытия ~75% на 24ч и ~80% на 48ч).

Если цена выходит за край коридора — сценарий не сработал.

## Пары

Монеты: BTC, ETH, SOL, BNB, XRP, DOGE, TON, ADA, AVAX, LINK, DOT, LTC, TRX, SUI, ATOM, NEAR, APT, ARB, OP, INJ, FIL, UNI, AAVE, PEPE, SHIB.

Котировки: USDT, USDC, FDUSD, EUR, TRY, BTC — какие есть у выбранной монеты.

## Автообновление

15 / 30 / 60 минут, либо вручную кнопкой «Проверить».

## Запуск

```bash
npm install
npm run dev
```

JSON API:

- `GET /api/v1/forecast?symbol=BTCUSDT`
- `GET /api/v1/health`
- `GET /api/v1/metrics`

Тесты алгоритма:

```bash
npm test
```

Магические числа — в `src/lib/corridor/config.ts`.
