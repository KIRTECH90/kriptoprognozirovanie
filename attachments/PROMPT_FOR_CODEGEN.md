# Промпт для нейросети-кодера

Скопируй этот блок целиком вместе с файлом CRYPTO_CORRIDOR_SPEC.md.

---

Ты старший инженер. Реализуй приложение строго по приложенной спецификации CRYPTO_CORRIDOR_SPEC.md. Не упрощай формулы «на глаз» и не заменяй калиброванный коридор одной точечной ценой.

## Задача
Сделать сервис прогноза коридора цены BTCUSDT на 24 и 48 часов:
технический анализ + простая математика волатильности + новости как модификатор ширины/асимметрии.
Центр коридора почти у текущей цены (shrinkage). Ширина адаптивная и калибруемая.

## Стек
- Python 3.11+
- FastAPI
- pandas, numpy, httpx
- SQLite (sqlite3 или SQLAlchemy)
- APScheduler
- pytest
- Frontend: минимальный одностраничный HTML+JS в static/ ИЛИ заготовка Telegram Mini App. Сделай веб-страницу, чтобы можно было открыть сразу.

## Правила реализации
1. Все магические числа только в config.py — как в спецификации.
2. Реализуй модули 1-в-1 по структуре из спецификации.
3. Формулы EMA, RSI Wilder, MACD, ATR, σ, μ, w, квантили — как написано. Не подменяй RSI на «простое среднее приростов» без Уайлдера.
4. Новости: дедуп обязателен. Нет ключей в коде. Если cryptocurrency.cv недоступен — RSS/заглушка пустого шока, stale_news=true, коридор не ломать.
5. Binance: публичные klines `https://api.binance.com/api/v3/klines`.
6. Fear & Greed: `https://api.alternative.me/fng/?limit=1`.
7. Никакой торговли, никаких фраз «купи/продай».
8. Напиши README: как запустить, что делает алгоритм, дисклеймер.
9. Напиши pytest на пункты из раздела 15 спецификации. Для тестов индикаторов можно замокать сеть.
10. Добавь скрипт `python -m app.cli` который печатает текущий прогноз в консоль.
11. Добавь `python -m app.calibrate` — walk-forward по истории 1h с Binance (лимит запросов уважать, паузы). Если сеть в тестах недоступна — калибровка должна уметь работать от сохранённого CSV.
12. Не ставь тяжёлые ML-библиотеки (torch, tf, sklearn не обязателен).
13. Если чего-то нет в спецификации — выбери самое простое и напиши TODO, не выдумывай новую модель.
14. Округли цены в API до 2 знаков для BTCUSDT, width_pct до 4 знаков.
15. После генерации выведи дерево файлов и как запустить.

## Критерий готовности
- `uvicorn app.main:app` поднимает API
- GET /api/v1/forecast возвращает JSON как в спецификации
- страница на / показывает коридоры
- тесты зелёные без реальной сети (моки)
- в README есть дисклеймер
