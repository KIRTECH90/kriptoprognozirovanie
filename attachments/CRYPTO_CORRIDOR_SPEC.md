# Спецификация алгоритма: калиброванный ценовой коридор крипты на 24ч / 48ч

Документ самодостаточный. Его можно целиком отдать другой нейросети как ТЗ на написание приложения.
Язык реализации приложения: любой. Рекомендуемый стек ниже.
Это НЕ торговый совет и НЕ обещание точной цены. Это система доверительного интервала.

---

## 0. Цель и жёсткие ограничения

### Цель
Для выбранного актива (старт: BTCUSDT) каждые 10 минут выдавать:

- текущую цену P0
- коридор на 24 часа: [L24, H24], центр M24
- коридор на 48 часов: [L48, H48], центр M48
- режим рынка
- уверенность 0–100
- до 3 драйверов текстом
- ожидаемое покрытие коридора (target coverage)

### Что значит «максимально точный коридор с небольшим разбегом»
Нельзя просто взять узкую константу. Узкий коридор, в который цена не попадает, бесполезен.

Оптимизируем так:

```
минимизировать median( (H - L) / P0 )
при условии coverage >= TARGET
```

- TARGET_24H = 0.75   (факт через 24ч внутри [L24, H24] в 75% случаев)
- TARGET_48H = 0.80
- Не используем 95% интервалы: на BTC они слишком широкие.
- Не обещаем «точный курс». Обещаем калиброванный диапазон.

### Запрещено в реализации
- Выдавать одну точку без коридора.
- Хардкодить ширину «всегда ±2%».
- Сдвигать центр на величину новостного заголовка без порога серьёзности.
- Обучать LSTM/нейросеть в v1.
- Показывать формулировки «завтра цена будет X».
- Торговать автоматически.

## 4. Индикаторы (точные формулы)

Все цены — close, если не сказано иначе.
Лог-доходность: r_t = ln(P_t / P_{t-1})

### EMA
```
EMA_1 = P_1
α = 2 / (n + 1)
EMA_t = α * P_t + (1-α) * EMA_{t-1}
```
Считать EMA20, EMA50, EMA200 на 1h, 4h, 1d.

### RSI(14) — Wilder
```
Δ = P_t - P_{t-1}
gain = max(Δ, 0), loss = max(-Δ, 0)
avg_gain, avg_loss — сглаживание Уайлдера 14
RS = avg_gain / avg_loss
RSI = 100 - 100 / (1 + RS)
```

### MACD
```
MACD = EMA12 - EMA26
Signal = EMA9(MACD)
Hist = MACD - Signal
```
На 1h.

### ATR(14)
```
TR = max(H-L, |H-prevC|, |L-prevC|)
ATR — сглаживание Уайлдера 14
atr_pct = ATR / close
```
Считать на 1h и 4h.

### Bollinger(20, 2) на 1h
```
MB = SMA20(close)
σ_bb = stdev20(close)
UB = MB + 2σ_bb
LB = MB - 2σ_bb
bb_pos = (close - LB) / (UB - LB)   # 0..1, клип
bb_width = (UB - LB) / MB
```

### Реализованная волатильность
На часовых свечах за последние 24 часа (24 точки):

```
σ_cc_24h = sqrt( sum(r_i^2) )                 # уже на горизонт 24ч, не годовая
```

Parkinson за те же 24 часа:

```
σ_pk_24h = sqrt( (1 / (4*ln(2))) * sum( ln(H_i/L_i)^2 ) )
```

Для 48ч:
```
σ_cc_48h = sqrt( sum(r_i^2 за 48 часовых свечей) )
σ_pk_48h аналогично
```

Не аннуализировать. Работать в единицах горизонта.

### Объём
```
vol_ratio = volume_last / SMA(volume, 20)   # на 1h
```

## 5. Режим рынка (обязателен для узкого коридора)

Считать на 4h как основном режиме, подтверждать 1d.

### Тренд
```
trend_up   если EMA20 > EMA50 > EMA200 на 4h И close > EMA50
trend_down если EMA20 < EMA50 < EMA200 на 4h И close < EMA50
иначе range
```

Дополнительно сила:
```
ema_sep = (EMA20 - EMA50) / ATR_4h
strong если abs(ema_sep) >= 0.8
```

### Волатильность режима
Сравнить текущий atr_pct_1h с медианой atr_pct_1h за 30 дней.

```
vol_high если atr_pct_now >= 1.25 * median_30d
vol_low  если atr_pct_now <= 0.80 * median_30d
иначе vol_mid
```

### Шок
```
event = true если
  news_shock >= 0.55
  ИЛИ atr_pct_now >= 1.8 * median_30d
  ИЛИ |r за последние 3 часа| >= 1.2 * σ_cc_24h
```

### Итоговые режимы
- TREND_UP_LOWVOL
- TREND_UP_MIDVOL
- TREND_UP_HIGHVOL
- RANGE_LOWVOL
- RANGE_MIDVOL
- RANGE_HIGHVOL
- TREND_DOWN_LOWVOL
- TREND_DOWN_MIDVOL
- TREND_DOWN_HIGHVOL
- EVENT

EVENT перекрывает остальные.

## 6. Новости: скоринг

Каждый уникальный заголовок:

### Тип (первое совпадение)
Словари ключевых слов (регистр игнорировать, RU+EN):

- HACK: hack, exploit, breach, drained, взлом, хак, эксплойт
- REGULATION: sec, ban, lawsuit, etf rejected, запрет, регулирование, иск
- MACRO: cpi, fomc, fed, rates, nfp, inflation, ставка, инфляц
- LISTING: listing, listed, etf approved, approved, листинг
- ADOPTION: reserve, treasury, buys bitcoin, adoption
- RUMOR: reportedly, sources say, may, might, слух, может
- NOISE: всё остальное

### Знак polarity ∈ {-1, 0, +1}
- HACK, ban, rejected, crash, liquidation cascade → -1
- approved, listing major, buys, inflows → +1
- иначе 0, если нет явных маркеров

### Сила severity ∈ {0.15, 0.35, 0.60, 0.85, 1.00}
- 1.00: взлом крупной биржи / запрет спота в крупной стране / неожиданный отказ ETF
- 0.85: FOMC/CPI в ближайшие 12 часов ИЛИ уже вышел сюрприз
- 0.60: крупный листинг / крупный приток / регуляторный сигнал средней силы
- 0.35: обычная аналитика с сильным заголовком, слух из нормального источника
- 0.15: шум, пересказ, «аналитик считает»

Если тип = RUMOR: severity *= 0.45
Если тип = NOISE: severity *= 0.25

### Новизна novelty ∈ [0, 1]
- 1.0 если тема не встречалась 24ч
- 0.4 если похожий заголовок был 3–24ч назад
- 0.1 если это дубль последнего часа

### Шок одной новости
```
s_i = polarity * severity * novelty
```
Для расширения коридора берём модуль |s_i|.

### Агрегат за окно 6 часов
```
news_shift = clip( sum(s_i), -1.2, 1.2 )
news_shock = clip( max(|s_i|) + 0.25*sum(|s_i|), 0, 1.5 )
```
Не суммировать 20 одинаковых перепечаток: после дедупа max 8 новостей в сумму.

Fear & Greed:
```
fg_adj = (50 - fg_value) / 200     # от -0.25 до +0.25, жадность чуть давит центр вниз
```
Вес малый, см. центр.

## 7. Оценка волатильности на горизонт (σ)

Бленд, устойчивый и не раздутый:

```
σ24_raw = 0.45 * ATR14_1h / close * sqrt(24)
        + 0.35 * σ_cc_24h
        + 0.20 * σ_pk_24h

σ48_raw = 0.40 * ATR14_4h / close * sqrt(12)   # 12 свечей 4h ≈ 48ч
        + 0.40 * σ_cc_48h
        + 0.20 * σ_pk_48h
```

Сглаживание, чтобы коридор не прыгал каждые 10 минут:
```
σ24 = 0.65 * σ24_raw + 0.35 * σ24_prev
σ48 = 0.65 * σ48_raw + 0.35 * σ48_prev
```
При первом запуске prev = raw.

Клип относительно истории 90 дней:
```
σ24 = clip(σ24, 0.55 * median_σ24_90d, 2.4 * median_σ24_90d)
```
То же для 48ч.

## 8. Центр коридора (медиана). Сильное сжатие дрейфа

На 1–2 дня дрейф крипты шумный. Поэтому центр почти не убегает от P0. Это критично для точности.

### Сырой теханал-скор S_ta ∈ [-1, 1]
```
s = 0
s += 0.30 если trend_up, -0.30 если trend_down
s += 0.15 если close > EMA20_1h, -0.15 иначе
s += clip( (50 - RSI14_1h) / 100, -0.20, 0.20 )   # перекупленность давит вверх-ожидание
s += clip( MACD_hist / (ATR_1h + 1e-12) * 0.10, -0.15, 0.15 )
S_ta = clip(s, -1, 1)
```

### Сырой дрейф в лог-пространстве
```
μ_raw_24 = 0.55 * S_ta * σ24 + 0.25 * r_last_24h + 0.20 * news_shift * σ24
μ_raw_48 = 0.50 * S_ta * σ48 + 0.20 * r_last_48h + 0.30 * news_shift * σ48
```

### Shrinkage к нулю (обязательно)
```
κ24 = 0.28
κ48 = 0.22
μ24 = κ24 * μ_raw_24 + (1 - κ24) * 0
μ48 = κ48 * μ_raw_48 + (1 - κ48) * 0
```
Плюс слабый Fear & Greed:
```
μ24 += 0.15 * fg_adj * σ24
μ48 += 0.12 * fg_adj * σ48
```

Клип центра:
```
μ24 = clip(μ24, -0.45 * σ24, 0.45 * σ24)
μ48 = clip(μ48, -0.50 * σ48, 0.50 * σ48)
```

Цены центра:
```
M24 = P0 * exp(μ24)
M48 = P0 * exp(μ48)
```

Интерпретация: центр почти всегда близко к текущей цене. Узкость достигается шириной, не «угадыванием точки».

## 9. Ширина коридора — главная часть

Строим асимметричный интервал в лог-доходностях, затем переводим в цену.

### 9.1 Базовые квантили из истории (предпочтительно)

Если в базе есть >= 80 прошлых окон того же режима за последние 400 дней:

Для каждого исторического момента t в том же режиме взять факт:
```
r24_fact = ln(P_{t+24h} / P_t)
```
Взять выборку r24_fact.

Пусть q_lo_emp и q_hi_emp — эмпирические квантили этой выборки.
Стартовые квантили (потом калибруются):

- 24ч, цель 75%: q_lo = 12.5-й перцентиль, q_hi = 87.5-й
- 48ч, цель 80%: q_lo = 10-й, q_hi = 90-й

Масштаб к текущей волатильности:
```
σ_emp = median(|r| * 1.2533) по выборке   # грубая оценка σ выборки
scale = clip(σ_now / (σ_emp + 1e-12), 0.70, 1.60)
q_lo *= scale
q_hi *= scale
```

### 9.2 Фоллбек без истории режима
Нормальное приближение, но с квантилями цели, не ±2σ:

```
z75 = 1.15    # примерно 75% массы N(0,1)
z80 = 1.28
q_lo_24 = -z75 * σ24
q_hi_24 = +z75 * σ24
q_lo_48 = -z80 * σ48
q_hi_48 = +z80 * σ48
```

### 9.3 Модификаторы ширины (чтобы разбег не был вечно широким)

Стартовый множитель w = 1.0

Сжать, если условия спокойные (все должны выполниться):
```
если режим содержит LOWVOL
И event == false
И news_shock < 0.25
И bb_width <= медианы bb_width за 30д
И 35 <= RSI <= 65
    w *= 0.82
```

Чуть сжать при согласии ТФ:
```
если тренд 1h, 4h, 1d совпадает по направлению
И event == false
    w *= 0.90
```

Расширить только по делу:
```
если EVENT:              w *= 1.35
иначе если HIGHVOL:      w *= 1.18
если news_shock >= 0.55: w *= 1.00 + 0.25 * news_shock
если vol_ratio >= 2.0:   w *= 1.08
если данные stale:       w *= 1.15
```

Клип множителя:
```
w = clip(w, 0.72, 1.70)
```

0.72 — нижний предел сжатия. Дальше нельзя, даже если хочется «узкий красивый» коридор.

### 9.4 Асимметрия
Если рынок перекуплен, верхняя сторона чуть уже, нижняя чуть шире (и наоборот).

```
a = clip( (RSI14_1h - 50) / 80, -0.35, 0.35 )
# a > 0 перекуплен: больше риска вниз
q_lo = q_lo * (1 + 0.35 * a)    # a>0 → q_lo более отрицательный (шире низ)
q_hi = q_hi * (1 - 0.25 * a)    # a>0 → верх уже
```

Новости той же логикой:
```
если news_shift < 0:  # негатив
    q_lo *= (1 + 0.20 * min(1, -news_shift))
если news_shift > 0:
    q_hi *= (1 + 0.15 * min(1, news_shift))
```

### 9.5 Сборка
```
L_log_24 = μ24 + w * q_lo_24
H_log_24 = μ24 + w * q_hi_24
гарантировать L_log_24 < 0 < H_log_24 относительно μ24, и H_log > L_log + 0.003

L24 = P0 * exp(L_log_24)
H24 = P0 * exp(H_log_24)
```
Аналогично 48ч.

Минимальная ширина (защита от нулевого коридора):
```
если (H24 - L24) / P0 < 0.012: расширить симметрично до 1.2%
для 48ч минимум 1.8%
```

Максимальная ширина (чтобы EVENT не рисовал ±25% на ровном месте без фактов):
```
если (H24 - L24) / P0 > 0.09 и режим != EVENT: сжать к 9%
если EVENT: максимум 14% на 24ч
для 48ч: 12% обычно, 18% EVENT
```

Эти капы подобраны под BTC. Для альта их нужно считать из его собственной медианы σ.

## 10. Уверенность и текст драйверов

```
width_pct = (H24 - L24) / P0
conf = 78
conf -= 18 если EVENT
conf -= 10 если HIGHVOL
conf -= 8  если news_shock >= 0.55
conf += 8  если LOWVOL и не EVENT
conf += 6  если тренды ТФ согласованы
conf -= 12 если stale
conf = clip(conf, 25, 88)
```

Высокая уверенность ≠ «цена будет тут». Это «режим спокойный, коридор имеет право быть уже».

Драйверы — до 3 коротких фраз из шаблонов:
- «Режим: тренд вверх, низкая волатильность — коридор сжат»
- «RSI 72, верхняя граница уже нижней»
- «Новостной шок 0.61 (MACRO), коридор расширен»
- «ТФ 1h/4h/1d не согласованы — ширина не сжималась»
- «Центр почти у рынка: дрейф ужат, чтобы не промахиваться»

## 11. Калибровка (обязательный офлайн-модуль)

Без этого коридор либо жирный, либо самоуверенно узкий.

Раз в сутки на истории 180–400 дней, walk-forward:

1. В каждой точке прошлого t (шаг 4 часа) прогнать алгоритм **без утечки будущего** (новости на t только с published_at <= t).
2. Сравнить [L24, H24] с P_{t+24h}.
3. Посчитать coverage и median_width.

Подгон:

```
если coverage_24 < TARGET_24H - 0.04:
    увеличить базовые |квантили| на 6%
если coverage_24 > TARGET_24H + 0.05 и median_width > цели:
    уменьшить |квантили| на 5%
квантили клипать: не уже чем z=0.95*σ и не шире чем z=1.50*σ для 24ч
```

То же для 48ч.

Сохранять в config/calibration.json:
```
{
  "q_lo_mult_24": 1.00,
  "q_hi_mult_24": 1.00,
  "q_lo_mult_48": 1.00,
  "q_hi_mult_48": 1.00,
  "last_coverage_24": null,
  "last_median_width_24": null,
  "updated_at": null
}
```

Старт множителей = 1.0. После первой калибровки на истории — применять всегда.

Цель по ширине для BTC на спокойном рынке (ориентир, не хардкод логики):
- 24ч median width ≈ 3.5–6.5%
- 48ч median width ≈ 5–9%
Если после калибровки coverage держится, а ширина выше — сначала проверить, не слишком ли часто EVENT.

## 15. Тесты, которые обязаны быть

1. EMA/RSI/ATR на коротком искусственном ряде — совпадение с эталоном вручную.
2. Дедуп новостей: два почти одинаковых заголовка → один шок.
3. LOWVOL + нет новостей + RSI 50 → w < 1.
4. EVENT → w > 1 и коридор шире, чем в тесте 3 на тех же σ.
5. Shrinkage: |μ24| < |μ_raw_24|.
6. L < M < H, L < P0*0.999 или H > P0*1.001 почти всегда, ширина >= минимума.
7. stale=true расширяет ширину.
8. Калибровочный шаг без заглядывания в будущее (news timestamp guard).
